Data Warehouse Corporativo:
Arquitectura Medallón & EDA

Diseño y construcción de un pipeline de datos end-to-end. Desde la implementación de gobierno de datos y convenciones de nomenclatura, hasta la ingesta de archivos planos (CRM/ERP), limpieza intensiva con T-SQL, modelado dimensional, y Análisis Exploratorio de Datos (EDA).

SQL Server T-SQL Data Governance Medallion Architecture Star Schema EDA

Gobierno de Datos & Convenciones de Nomenclatura

Un Data Warehouse robusto requiere un estándar riguroso. Se implementaron reglas estrictas de Naming Conventions utilizando snake_case para asegurar la coherencia en todos los esquemas lógicos y facilitar la trazabilidad del linaje de datos entre las fuentes de origen (CRM/ERP) y las tablas analíticas.

  • Estandarización de Tablas Crudas (Bronce & Plata)Las entidades mantienen el nombre de su sistema de origen para asegurar trazabilidad. Patrón: <sourcesystem>_<entity> (Ej. crm_customer_info).
  • Modelado de Negocio (Oro)Las tablas finales utilizan nombres descriptivos alineados al dominio de negocio, utilizando los prefijos dim_ para Dimensiones y fact_ para Hechos.
  • Metadatos Técnicos & AuditoríaToda columna autogenerada por el sistema para propósitos de auditoría inicia con el prefijo dwh_ (Ej. dwh_create_date). Toda llave subrogada utiliza el sufijo _key.

Diseño de Arquitectura y Metodología ETL

Integrando conceptos de Kimball y Data Lakehouses, se diseñó una Arquitectura Medallón lógica en SQL Server. Esta aproximación garantiza la separación de responsabilidades (SoC) entre la ingesta cruda, la transformación y el consumo de datos.

Capa de Datos Objetivo y Tipo de Objeto Transformaciones Aplicadas Método de Carga
Capa Bronce Trazabilidad. Tablas físicas (Raw Tables). Datos almacenados "As-Is". Ninguna (As-Is). Carga Completa (Truncate & Insert).
Capa Plata Limpieza y preparación. Tablas físicas (Cleaned Tables). Data Cleansing, Normalización, Estandarización y Columnas Derivadas. Carga Completa (Truncate & Insert).
Capa Oro Consumo por negocio (BI & Analytics). Vistas Analíticas. Data Integration, Agregaciones, Lógica de Negocio y Data Modeling (Star Schema). Ninguna (Son Vistas en tiempo real).

Fase 1: Capa Bronce (Data Ingestion)

1. Definición del Esquema Físico (DDL As-Is)

La prioridad en la Capa Bronce es la extracción veloz y fiel a la fuente original (As-Is). Al modelar las tablas de ingesta, se mantuvo deliberadamente la estructura cruda para evitar que el BULK INSERT falle. Un ejemplo destacado es la tabla de ventas, donde las fechas del CRM se mantuvieron como tipo numérico (INT), delegando la limpieza de tipos de datos a la Capa Plata.

2. Motor de Ingesta Automatizado

Se desarrolló un motor de ingesta masiva centralizado para todas las fuentes (CRM y ERP). Implementa un método BULK INSERT bajo el estándar de carga completa (Full Load). Se aplicó un patrón Idempotente de reinicio seguro (TRUNCATE antes de insertar), auditoría de tiempos de ejecución y manejo de errores mediante TRY...CATCH.

proc_load_bronze.sql (Motor de Ingesta Completo) 
/*
===============================================================================
Stored Procedure: Load Bronze Layer (Source -> Bronze)
===============================================================================
Propósito:
    Carga datos en el esquema 'bronze' desde archivos CSV externos.
    - Trunca las tablas antes de cargar (Idempotencia).
    - Usa `BULK INSERT` para ingesta masiva optimizada.
===============================================================================
*/
CREATE OR ALTER PROCEDURE bronze.load_bronze AS
BEGIN
    -- Declaración de variables para auditoría de rendimiento
    DECLARE @start_time DATETIME, @end_time DATETIME, @batch_start_time DATETIME, @batch_end_time DATETIME; 
    
    BEGIN TRY
        SET @batch_start_time = GETDATE();
        PRINT '================================================';
        PRINT 'Loading Bronze Layer';
        PRINT '================================================';

        -- ------------------------------------------------
        -- 1. Carga de Tablas CRM
        -- ------------------------------------------------
        PRINT '------------------------------------------------';
        PRINT 'Loading CRM Tables';
        PRINT '------------------------------------------------';

        SET @start_time = GETDATE();
        PRINT '>> Truncating Table: bronze.crm_cust_info';
        TRUNCATE TABLE bronze.crm_cust_info; -- Limpieza de tabla para evitar duplicados en reinicios
        
        PRINT '>> Inserting Data Into: bronze.crm_cust_info';
        BULK INSERT bronze.crm_cust_info
        FROM 'C:\SQL_Datasets\datasets\source_crm\cust_info.csv'
        WITH (
            FIRSTROW = 2,
            FIELDTERMINATOR = ',',
            TABLOCK -- Optimización clave: Bloquea la tabla completa en memoria acelerando la escritura masiva
        );
        SET @end_time = GETDATE();
        PRINT '>> Load Duration: ' + CAST(DATEDIFF(second, @start_time, @end_time) AS NVARCHAR) + ' seconds';
        PRINT '>> -------------';

        SET @start_time = GETDATE();
        PRINT '>> Truncating Table: bronze.crm_prd_info';
        TRUNCATE TABLE bronze.crm_prd_info;

        PRINT '>> Inserting Data Into: bronze.crm_prd_info';
        BULK INSERT bronze.crm_prd_info
        FROM 'C:\SQL_Datasets\datasets\source_crm\prd_info.csv'
        WITH ( FIRSTROW = 2, FIELDTERMINATOR = ',', TABLOCK );
        SET @end_time = GETDATE();
        PRINT '>> Load Duration: ' + CAST(DATEDIFF(second, @start_time, @end_time) AS NVARCHAR) + ' seconds';
        PRINT '>> -------------';

        SET @start_time = GETDATE();
        PRINT '>> Truncating Table: bronze.crm_sales_details';
        TRUNCATE TABLE bronze.crm_sales_details;
        
        PRINT '>> Inserting Data Into: bronze.crm_sales_details';
        BULK INSERT bronze.crm_sales_details
        FROM 'C:\SQL_Datasets\datasets\source_crm\sales_details.csv'
        WITH ( FIRSTROW = 2, FIELDTERMINATOR = ',', TABLOCK );
        SET @end_time = GETDATE();
        PRINT '>> Load Duration: ' + CAST(DATEDIFF(second, @start_time, @end_time) AS NVARCHAR) + ' seconds';
        PRINT '>> -------------';

        -- ------------------------------------------------
        -- 2. Carga de Tablas ERP
        -- ------------------------------------------------
        PRINT '------------------------------------------------';
        PRINT 'Loading ERP Tables';
        PRINT '------------------------------------------------';
        
        SET @start_time = GETDATE();
        PRINT '>> Truncating Table: bronze.erp_loc_a101';
        TRUNCATE TABLE bronze.erp_loc_a101;
        
        PRINT '>> Inserting Data Into: bronze.erp_loc_a101';
        BULK INSERT bronze.erp_loc_a101
        FROM 'C:\SQL_Datasets\datasets\source_erp\LOC_A101.csv'
        WITH ( FIRSTROW = 2, FIELDTERMINATOR = ',', TABLOCK );
        SET @end_time = GETDATE();
        PRINT '>> Load Duration: ' + CAST(DATEDIFF(second, @start_time, @end_time) AS NVARCHAR) + ' seconds';
        PRINT '>> -------------';

        SET @start_time = GETDATE();
        PRINT '>> Truncating Table: bronze.erp_cust_az12';
        TRUNCATE TABLE bronze.erp_cust_az12;
        
        PRINT '>> Inserting Data Into: bronze.erp_cust_az12';
        BULK INSERT bronze.erp_cust_az12
        FROM 'C:\SQL_Datasets\datasets\source_erp\CUST_AZ12.csv'
        WITH ( FIRSTROW = 2, FIELDTERMINATOR = ',', TABLOCK );
        SET @end_time = GETDATE();
        PRINT '>> Load Duration: ' + CAST(DATEDIFF(second, @start_time, @end_time) AS NVARCHAR) + ' seconds';
        PRINT '>> -------------';

        SET @start_time = GETDATE();
        PRINT '>> Truncating Table: bronze.erp_px_cat_g1v2';
        TRUNCATE TABLE bronze.erp_px_cat_g1v2;
        
        PRINT '>> Inserting Data Into: bronze.erp_px_cat_g1v2';
        BULK INSERT bronze.erp_px_cat_g1v2
        FROM 'C:\SQL_Datasets\datasets\source_erp\PX_CAT_G1V2.csv'
        WITH ( FIRSTROW = 2, FIELDTERMINATOR = ',', TABLOCK );
        SET @end_time = GETDATE();
        PRINT '>> Load Duration: ' + CAST(DATEDIFF(second, @start_time, @end_time) AS NVARCHAR) + ' seconds';
        PRINT '>> -------------';

        PRINT '=========================================='
        PRINT 'Loading Bronze Layer is Completed';
        PRINT '   - Total Load Duration: ' + CAST(DATEDIFF(SECOND, @batch_start_time, @batch_end_time) AS NVARCHAR) + ' seconds';
        PRINT '=========================================='

        -- Captura y registro de errores a nivel de base de datos en caso de fallo de ingesta
        PRINT '=========================================='
        PRINT 'ERROR OCCURED DURING LOADING BRONZE LAYER'
        PRINT 'Error Message: ' + ERROR_MESSAGE();
        PRINT 'Error Number: ' + CAST(ERROR_NUMBER() AS NVARCHAR);
        PRINT 'Error State: ' + CAST(ERROR_STATE() AS NVARCHAR);
        PRINT '=========================================='
    END CATCH
END

2. Automatización y Transformación ETL (Stored Procedure Maestro)

La limpieza de datos (Data Cleansing) se orquestó mediante un sofisticado Stored Procedure maestro (silver.load_silver). Este motor extrae los datos crudos, aplica reglas de negocio mediante CASE WHEN, limpia texto con TRIM, recalcula métricas faltantes, unifica formatos de fecha y normaliza historiales usando funciones analíticas como ROW_NUMBER() y LEAD().

proc_load_silver.sql (Motor de Transformación Completo) 
/*
===============================================================================
Stored Procedure: Load Silver Layer (Bronze -> Silver)
===============================================================================
Propósito:
    Ejecuta el proceso ETL para transformar y cargar los datos desde 'bronze' 
    hacia 'silver'. Aplica limpieza profunda, normalización y cálculos derivados.
===============================================================================
*/
CREATE OR ALTER PROCEDURE silver.load_silver AS
BEGIN
    DECLARE @start_time DATETIME, @end_time DATETIME, @batch_start_time DATETIME, @batch_end_time DATETIME; 
    BEGIN TRY
        SET @batch_start_time = GETDATE();
        PRINT '================================================';
        PRINT 'Loading Silver Layer';
        PRINT '================================================';

        -- ------------------------------------------------
        -- 1. Transformación CRM Tables
        -- ------------------------------------------------
        
        -- Carga de crm_cust_info (Eliminación de duplicados y limpieza de strings)
        SET @start_time = GETDATE();
        PRINT '>> Truncating Table: silver.crm_cust_info';
        TRUNCATE TABLE silver.crm_cust_info;
        PRINT '>> Inserting Data Into: silver.crm_cust_info';
        INSERT INTO silver.crm_cust_info (cst_id, cst_key, cst_firstname, cst_lastname, cst_marital_status, cst_gndr, cst_create_date)
        SELECT
            cst_id,
            cst_key,
            TRIM(cst_firstname) AS cst_firstname,
            TRIM(cst_lastname) AS cst_lastname,
            CASE 
                WHEN UPPER(TRIM(cst_marital_status)) = 'S' THEN 'Single'
                WHEN UPPER(TRIM(cst_marital_status)) = 'M' THEN 'Married'
                ELSE 'n/a'
            END AS cst_marital_status, -- Normalización de diccionario de Estado Civil
            CASE 
                WHEN UPPER(TRIM(cst_gndr)) = 'F' THEN 'Female'
                WHEN UPPER(TRIM(cst_gndr)) = 'M' THEN 'Male'
                ELSE 'n/a'
            END AS cst_gndr, -- Normalización de diccionario de Género
            cst_create_date
        FROM (
            -- Selección del registro más reciente en caso de id duplicados (Deduplicación)
            SELECT
                *,
                ROW_NUMBER() OVER (PARTITION BY cst_id ORDER BY cst_create_date DESC) AS flag_last
            FROM bronze.crm_cust_info
            WHERE cst_id IS NOT NULL
        ) t
        WHERE flag_last = 1;
        SET @end_time = GETDATE();
        PRINT '>> Load Duration: ' + CAST(DATEDIFF(SECOND, @start_time, @end_time) AS NVARCHAR) + ' seconds';

        -- Carga de crm_prd_info (Separación de Strings y SCD)
        SET @start_time = GETDATE();
        PRINT '>> Truncating Table: silver.crm_prd_info';
        TRUNCATE TABLE silver.crm_prd_info;
        PRINT '>> Inserting Data Into: silver.crm_prd_info';
        INSERT INTO silver.crm_prd_info (prd_id, cat_id, prd_key, prd_nm, prd_cost, prd_line, prd_start_dt, prd_end_dt)
        SELECT
            prd_id,
            REPLACE(SUBSTRING(prd_key, 1, 5), '-', '_') AS cat_id, -- Extracción de categoría
            SUBSTRING(prd_key, 7, LEN(prd_key)) AS prd_key,        -- Extracción de Product Key puro
            prd_nm,
            ISNULL(prd_cost, 0) AS prd_cost,
            CASE 
                WHEN UPPER(TRIM(prd_line)) = 'M' THEN 'Mountain'
                WHEN UPPER(TRIM(prd_line)) = 'R' THEN 'Road'
                WHEN UPPER(TRIM(prd_line)) = 'S' THEN 'Other Sales'
                WHEN UPPER(TRIM(prd_line)) = 'T' THEN 'Touring'
                ELSE 'n/a'
            END AS prd_line, 
            CAST(prd_start_dt AS DATE) AS prd_start_dt,
            CAST(
                LEAD(prd_start_dt) OVER (PARTITION BY prd_key ORDER BY prd_start_dt) - 1 
                AS DATE
            ) AS prd_end_dt -- Cálculo automático de Fecha Fin (SCD Tipo 2)
        FROM bronze.crm_prd_info;
        SET @end_time = GETDATE();
        PRINT '>> Load Duration: ' + CAST(DATEDIFF(SECOND, @start_time, @end_time) AS NVARCHAR) + ' seconds';

        -- Carga de crm_sales_details (Validación Matemática y de Fechas)
        SET @start_time = GETDATE();
        PRINT '>> Truncating Table: silver.crm_sales_details';
        TRUNCATE TABLE silver.crm_sales_details;
        PRINT '>> Inserting Data Into: silver.crm_sales_details';
        INSERT INTO silver.crm_sales_details (sls_ord_num, sls_prd_key, sls_cust_id, sls_order_dt, sls_ship_dt, sls_due_dt, sls_sales, sls_quantity, sls_price)
        SELECT DISTINCT
            sls_ord_num,
            sls_prd_key,
            sls_cust_id,
            CASE 
                WHEN sls_order_dt = 0 OR LEN(sls_order_dt) != 8 THEN NULL
                ELSE CAST(CAST(sls_order_dt AS VARCHAR) AS DATE) -- Casting de INT a DATE (YYYYMMDD)
            END AS sls_order_dt,
            CASE 
                WHEN sls_ship_dt = 0 OR LEN(sls_ship_dt) != 8 THEN NULL
                ELSE CAST(CAST(sls_ship_dt AS VARCHAR) AS DATE)
            END AS sls_ship_dt,
            CASE 
                WHEN sls_due_dt = 0 OR LEN(sls_due_dt) != 8 THEN NULL
                ELSE CAST(CAST(sls_due_dt AS VARCHAR) AS DATE)
            END AS sls_due_dt,
            CASE 
                WHEN sls_sales IS NULL OR sls_sales <= 0 OR sls_sales != sls_quantity * ABS(sls_price) 
                    THEN sls_quantity * ABS(sls_price) -- Recalcula ventas si el origen está corrupto
                ELSE sls_sales
            END AS sls_sales, 
            sls_quantity,
            CASE 
                WHEN sls_price IS NULL OR sls_price <= 0 
                    THEN sls_sales / NULLIF(sls_quantity, 0) -- Deriva el precio / Evita división por cero
                ELSE sls_price  
            END AS sls_price
        FROM bronze.crm_sales_details;
        SET @end_time = GETDATE();
        PRINT '>> Load Duration: ' + CAST(DATEDIFF(SECOND, @start_time, @end_time) AS NVARCHAR) + ' seconds';

        -- ------------------------------------------------
        -- 2. Transformación ERP Tables
        -- ------------------------------------------------
        
        -- Carga de erp_cust_az12 (Limpieza de ID's y Control de Fechas futuras)
        SET @start_time = GETDATE();
        PRINT '>> Truncating Table: silver.erp_cust_az12';
        TRUNCATE TABLE silver.erp_cust_az12;
        PRINT '>> Inserting Data Into: silver.erp_cust_az12';
        INSERT INTO silver.erp_cust_az12 (cid, bdate, gen)
        SELECT
            CASE
                WHEN cid LIKE 'NAS%' THEN SUBSTRING(cid, 4, LEN(cid)) -- Limpieza del prefijo ERP erróneo
                ELSE cid
            END AS cid, 
            CASE
                WHEN bdate > GETDATE() THEN NULL -- Convierte nacimientos futuros irreales a NULL
                ELSE bdate
            END AS bdate, 
            CASE
                WHEN UPPER(TRIM(gen)) IN ('F', 'FEMALE') THEN 'Female'
                WHEN UPPER(TRIM(gen)) IN ('M', 'MALE') THEN 'Male'
                ELSE 'n/a'
            END AS gen 
        FROM bronze.erp_cust_az12;
        SET @end_time = GETDATE();
        PRINT '>> Load Duration: ' + CAST(DATEDIFF(SECOND, @start_time, @end_time) AS NVARCHAR) + ' seconds';

        -- Carga de erp_loc_a101
        SET @start_time = GETDATE();
        PRINT '>> Truncating Table: silver.erp_loc_a101';
        TRUNCATE TABLE silver.erp_loc_a101;
        PRINT '>> Inserting Data Into: silver.erp_loc_a101';
        INSERT INTO silver.erp_loc_a101 (cid, cntry)
        SELECT
            REPLACE(cid, '-', '') AS cid, 
            CASE
                WHEN TRIM(cntry) = 'DE' THEN 'Germany'
                WHEN TRIM(cntry) IN ('US', 'USA') THEN 'United States'
                WHEN TRIM(cntry) = '' OR cntry IS NULL THEN 'n/a'
                ELSE TRIM(cntry)
            END AS cntry 
        FROM bronze.erp_loc_a101;
        SET @end_time = GETDATE();
        PRINT '>> Load Duration: ' + CAST(DATEDIFF(SECOND, @start_time, @end_time) AS NVARCHAR) + ' seconds';
        
        -- Carga de erp_px_cat_g1v2
        SET @start_time = GETDATE();
        PRINT '>> Truncating Table: silver.erp_px_cat_g1v2';
        TRUNCATE TABLE silver.erp_px_cat_g1v2;
        PRINT '>> Inserting Data Into: silver.erp_px_cat_g1v2';
        INSERT INTO silver.erp_px_cat_g1v2 (id, cat, subcat, maintenance)
        SELECT id, cat, subcat, maintenance FROM bronze.erp_px_cat_g1v2;
        SET @end_time = GETDATE();

        SET @batch_end_time = GETDATE();
        PRINT '=========================================='
        PRINT 'Loading Silver Layer is Completed';
        PRINT '   - Total Load Duration: ' + CAST(DATEDIFF(SECOND, @batch_start_time, @batch_end_time) AS NVARCHAR) + ' seconds';
        PRINT '=========================================='
        
    END TRY
    BEGIN CATCH
        PRINT '=========================================='
        PRINT 'ERROR OCCURED DURING LOADING SILVER LAYER'
        PRINT 'Error Message: ' + ERROR_MESSAGE();
        PRINT 'Error Number: ' + CAST(ERROR_NUMBER() AS NVARCHAR);
        PRINT 'Error State: ' + CAST(ERROR_STATE() AS NVARCHAR);
        PRINT '=========================================='
    END CATCH
END

3. Suite de Pruebas (Data Quality Assurance)

Una vez finalizada la inserción masiva, se ejecuta un script de validación (QA) para auditar la integridad de la base de datos, garantizando la exactitud de los datos limpios antes de pasar al modelado dimensional.

quality_checks_silver.sql (Data Profiling & QA) 
/*
===============================================================================
Pruebas de Calidad (Data Profiling & QA)
===============================================================================
Propósito:

    Incluye validaciones críticas para:
    - Nulos o duplicados en Llaves Primarias (Integridad de Entidades).
    - Espacios no deseados en campos de texto (Data Cleansing).
    - Rangos cronológicos inválidos (Reglas de Fechas).
    - Consistencia Matemática (Ventas = Cantidad * Precio).
===============================================================================
*/

-- ====================================================================
-- Auditando 'silver.crm_cust_info'
-- ====================================================================
-- Revisión de duplicados o nulos en Llave Primaria (Esperado: 0 Resultados)
SELECT 
    cst_id,

-- Verificación de espacios en blanco residuales (Esperado: 0 Resultados)
SELECT 
    cst_key

-- Estandarización de Datos: Validar valores categóricos correctos
SELECT DISTINCT 
    cst_marital_status 
FROM silver.crm_cust_info;

    prd_id,

HAVING COUNT(*) > 1 OR prd_id IS NULL;

-- Verificación de espacios en blanco residuales
SELECT 
    prd_nm 
FROM silver.crm_prd_info
WHERE prd_nm != TRIM(prd_nm);

-- Evitar costos nulos o valores negativos imposibles
SELECT 
    prd_cost 
FROM silver.crm_prd_info
WHERE prd_cost < 0 OR prd_cost IS NULL;

-- Regla de Negocio: Fecha de inicio debe ser siempre menor a Fecha fin
SELECT

FROM silver.crm_prd_info

-- ====================================================================
-- Auditando 'silver.crm_sales_details'
-- ====================================================================
-- Bloquear fechas fuera de rango histórico lógico (Esperado: 0 Resultados)

    NULLIF(sls_due_dt, 0) AS sls_due_dt

    OR LEN(sls_due_dt) != 8

Fase 3: Capa Oro (Modelado Dimensional)

1. Creación del Modelo Estrella (Star Schema Views)

La capa analítica final se construyó mediante Vistas Analíticas. Se implementó un Modelo de Estrella conectando la tabla de hechos con las dimensiones mediante Llaves Subrogadas (Surrogate Keys) dinámicas, asegurando el aislamiento del Data Warehouse respecto a los cambios en el CRM/ERP.

Modelo Dimensional en Estrella (Data Mart)

Diseño Entidad-Relación final implementado en la Capa Oro: fact_sales unida mediante Foreign Keys a las dimensiones dim_customers y dim_products.

Haz clic para ver el diagrama
ddl_gold.sql (Generación de Vistas Estrella) 
/*
===============================================================================
Script DDL: Creación de Vistas Capa Oro (Gold Layer)
===============================================================================
Propósito:
    Construye las vistas analíticas definitivas (Modelo Estrella).
    Transforma y combina la data limpia de la Capa Plata para entregar un 
    dataset enriquecido y listo para consumo de negocio (BI / Reportes).
===============================================================================
*/

-- =============================================================================
-- Dimensión: Clientes (gold.dim_customers)
-- =============================================================================
IF OBJECT_ID('gold.dim_customers', 'V') IS NOT NULL
    DROP VIEW gold.dim_customers;
GO

CREATE VIEW gold.dim_customers AS
SELECT
    -- Generación de Llave Subrogada (Aislamiento analítico)
    ROW_NUMBER() OVER (ORDER BY cst_id) AS customer_key, 
    ci.cst_id                          AS customer_id,
    ci.cst_key                         AS customer_number,
    ci.cst_firstname                   AS first_name,
    ci.cst_lastname                    AS last_name,
    la.cntry                           AS country,
    ci.cst_marital_status              AS marital_status,
    -- Master Data Management (MDM): Regla de prioridad de fuentes
    CASE 
        WHEN ci.cst_gndr != 'n/a' THEN ci.cst_gndr -- CRM es la fuente principal
        ELSE COALESCE(ca.gen, 'n/a')               -- ERP como fuente de respaldo
    END                                AS gender,
    ca.bdate                           AS birthdate,
    ci.cst_create_date                 AS create_date
FROM silver.crm_cust_info ci
LEFT JOIN silver.erp_cust_az12 ca
    ON ci.cst_key = ca.cid
LEFT JOIN silver.erp_loc_a101 la
    ON ci.cst_key = la.cid;
GO

-- =============================================================================
-- Dimensión: Productos (gold.dim_products)
-- =============================================================================
IF OBJECT_ID('gold.dim_products', 'V') IS NOT NULL
    DROP VIEW gold.dim_products;
GO

CREATE VIEW gold.dim_products AS
SELECT
    -- Llave Subrogada basada en el inicio de vigencia (SCD)
    ROW_NUMBER() OVER (ORDER BY pn.prd_start_dt, pn.prd_key) AS product_key, 
    pn.prd_id       AS product_id,
    pn.prd_key      AS product_number,
    pn.prd_nm       AS product_name,
    pn.cat_id       AS category_id,
    pc.cat          AS category,
    pc.subcat       AS subcategory,
    pc.maintenance  AS maintenance,
    pn.prd_cost     AS cost,
    pn.prd_line     AS product_line,
    pn.prd_start_dt AS start_date
FROM silver.crm_prd_info pn
LEFT JOIN silver.erp_px_cat_g1v2 pc
    ON pn.cat_id = pc.id
WHERE pn.prd_end_dt IS NULL; -- Filtro SCD Tipo 2: Solo devuelve los registros activos
GO

-- =============================================================================
-- Tabla de Hechos: Ventas (gold.fact_sales)
-- =============================================================================
IF OBJECT_ID('gold.fact_sales', 'V') IS NOT NULL
    DROP VIEW gold.fact_sales;
GO

CREATE VIEW gold.fact_sales AS
SELECT
    sd.sls_ord_num  AS order_number,
    pr.product_key  AS product_key,  -- Foreign Key hacia Dimensión Productos
    cu.customer_key AS customer_key, -- Foreign Key hacia Dimensión Clientes
    sd.sls_order_dt AS order_date,
    sd.sls_ship_dt  AS shipping_date,
    sd.sls_due_dt   AS due_date,
    sd.sls_sales    AS sales_amount,
    sd.sls_quantity AS quantity,
    sd.sls_price    AS price
FROM silver.crm_sales_details sd
LEFT JOIN gold.dim_products pr
    ON sd.sls_prd_key = pr.product_number
LEFT JOIN gold.dim_customers cu
    ON sd.sls_cust_id = cu.customer_id;
GO

2. Suite de Pruebas de Calidad (Data Quality Assurance - Capa Oro)

Como paso definitivo antes de conectar este Data Warehouse a herramientas de Business Intelligence (Power BI), se implementó un testeo riguroso del Esquema Estrella para prevenir fugas de datos y productos cartesianos (inflación de ventas).

quality_checks_gold.sql (Validación del Modelo Dimensional) 
/*
===============================================================================
Pruebas de Calidad (QA) - Capa Oro (Star Schema)
===============================================================================
Propósito:
    Validar la integridad, consistencia y precisión de la Capa Oro.
    Garantiza que el modelo dimensional esté listo para herramientas de BI verificando:
    - Unicidad de las llaves subrogadas (Surrogate Keys) en las dimensiones.
    - Integridad referencial exacta entre la tabla de hechos y las dimensiones.
===============================================================================
*/

-- ====================================================================
-- Auditando 'gold.dim_customers'
-- ====================================================================
-- Verificación de Unicidad de la Llave Subrogada (Customer Key)
-- Objetivo: Prevenir productos cartesianos (duplicidad de datos) en los joins.
-- Esperado: 0 Resultados 
SELECT 
    customer_key,
    COUNT(*) AS duplicate_count
FROM gold.dim_customers
GROUP BY customer_key
HAVING COUNT(*) > 1;

-- ====================================================================
-- Auditando 'gold.dim_products'
-- ====================================================================
-- Verificación de Unicidad de la Llave Subrogada (Product Key)
-- Esperado: 0 Resultados 
SELECT 
    product_key,
    COUNT(*) AS duplicate_count
FROM gold.dim_products
GROUP BY product_key
HAVING COUNT(*) > 1;

-- ====================================================================
-- Auditando 'gold.fact_sales'
-- ====================================================================
-- Verificación de Integridad Referencial en el Modelo de Datos
-- Objetivo: Detectar registros huérfanos. Si una venta no tiene cliente o 
-- producto asignado, aparecerá como "(En blanco)" en Power BI, dañando la analítica.
-- Esperado: 0 Resultados
SELECT * 
FROM gold.fact_sales f
LEFT JOIN gold.dim_customers c
    ON c.customer_key = f.customer_key
LEFT JOIN gold.dim_products p
    ON p.product_key = f.product_key
WHERE p.product_key IS NULL 
   OR c.customer_key IS NULL;

Fase 4: Análisis Exploratorio (EDA)

Tras modelar el Data Warehouse, ejecutamos un proceso de Análisis Exploratorio (EDA) para interrogar la Capa Oro utilizando T-SQL. A través de agregaciones y segmentaciones cruzadas entre Dimensiones y Medidas, se descubrieron tendencias críticas para el negocio y Insights procesables.

eda_analysis.sql (Ranking con Window Functions) 
-- Reporte: Identificar los 5 productos más rentables del histórico
SELECT * FROM (
    SELECT 
        p.product_name,
        SUM(f.sales_amount) AS total_revenue,
        RANK() OVER (ORDER BY SUM(f.sales_amount) DESC) AS sales_rank
    FROM gold.fact_sales f
    LEFT JOIN gold.dim_products p 
        ON f.product_key = p.product_key
    GROUP BY p.product_name
) ranking_query
WHERE sales_rank <= 5;
